## What this phase is

This phase establishes the **foundation** of MercyBridge's HIPAA Security Program. It profiles the organization and confirms its **covered-entity** status, maps the regulator (OCR) and the full obligation set (the HIPAA Security, Privacy, and Breach Notification Rules; HITECH; NIST SP 800-66 Rev. 2; HITRUST CSF; and readiness for the 2025 Security Rule NPRM), **designates the HIPAA Security Official** as §164.308(a)(2) requires, and defines governance, roles, scope, the roadmap, and the compliance obligations calendar. Everything downstream — the ePHI inventory, the risk analysis, the safeguards, business-associate management, and breach response — sits on this foundation.
