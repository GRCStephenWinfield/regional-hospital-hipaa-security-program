## Context
MercyBridge needs a defensible methodology for implementing the Security Rule and a recognized assurance mechanism, plus resilience to the pending Security Rule overhaul.

## Decision
Adopt **NIST SP 800-66 Rev.2** as the implementation methodology and pursue a **HITRUST i1 Validated Assessment**; build controls to the **2025 NPRM strengthened requirements** (MFA, encryption, asset inventory, annual pen testing, segmentation) as forward-looking readiness.

## Alternatives Considered
**Security Rule text only** — rejected: less actionable; misses NPRM direction. **Full HITRUST r2** — deferred: disproportionate for the first cycle; i1 is right-sized.

## Consequences
Current, examiner-recognized methodology; certifiable assurance; readiness for the final rule.
