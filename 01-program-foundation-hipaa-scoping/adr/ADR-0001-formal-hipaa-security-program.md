## Context
The HIPAA Security Rule (§164.308(a)(1)) requires a governed security management process to protect ePHI. MercyBridge's controls existed but were not consolidated under a single accountable program.

## Decision
Charter a **formal HIPAA Security Program** owned by the Security Official, overseen by the Board Audit & Compliance Committee, covering the administrative, physical, and technical safeguards, business associates, and breach response.

## Alternatives Considered
**Keep security decentralized** — rejected: no single accountable owner; OCR risk. **Rely on the EHR vendor** — rejected: a covered entity cannot outsource accountability.

## Consequences
Single accountable owner; documented governance; a defensible program for OCR.
