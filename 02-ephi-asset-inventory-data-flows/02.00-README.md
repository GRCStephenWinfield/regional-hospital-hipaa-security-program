## What this phase is

The HIPAA Security Rule protects ePHI — so the program has to know, precisely, **where ePHI lives and how it moves**. This phase delivers that: discovery across **210 enterprise information systems**, identification of the **68 that create, receive, maintain, or transmit ePHI**, end-to-end **data-flow mapping** from point of care through billing, health information exchange, and archival, a catalogue of the **6,120-device medical device / IoMT fleet**, network segmentation, cloud and hosted services, a four-tier **data classification scheme**, the **designated record set**, retention and disposal, and asset ownership.

This is not paperwork for its own sake: **§164.308(a)(1)(ii)(A) requires an accurate and thorough risk analysis**, and a risk analysis is only accurate if it rests on a complete picture of the ePHI estate. The 2025 Security Rule NPRM would make a formal asset inventory and network map **mandatory** — MercyBridge satisfies that in advance.
